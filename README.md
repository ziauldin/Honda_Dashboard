# 🚗 Honda Vehicle Sales Dashboard

A Power BI dashboard on about 4,200 Honda vehicle listings from US sellers. It compares price, condition, mileage, and consumer ratings across models, years, states, and seller types, following the KPIs set out in the problem statement in this repo.

## 📊 What it shows
- Average consumer rating by model, year, and condition (new or used)
- Price distribution by model and condition
- Mileage against price for used cars
- Ratings for comfort, interior, performance, value, styling, and reliability
- Breakdowns by state, seller type, drivetrain, fuel type, and transmission

## 🗂️ Data
- `honda_sell_data.xlsx`: 4,245 listings with 25 columns (year, model, condition, price, mileage, MPG, ratings, state, seller type, and more)
- `Honda_Vehicle_Dataset_KPI_and_Problem_Statement.docx`: the KPIs and the business problem
- `Honda Dashboard Details.docx` and `Honda Dashboard Report (1).docx`: the dashboard write-up and findings

## ▶️ How to open
Install [Power BI Desktop](https://www.microsoft.com/power-bi/desktop) (free, Windows), then open `Honda Dashboard.pbix`. If Power BI asks for the data source, point it to `honda_sell_data.xlsx` in this folder.
